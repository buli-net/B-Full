B-Lite local source integration status

Integrated local source modules:
- bitcoinj-core 0.17.1
- bcprov-source (Bouncy Castle 1.83)
- guava-source (Guava 33.7.2-android source)
- protobuf-lite-source (Protobuf Java Lite 4.36.2 source)
- slf4j-api-source and slf4j-android-source (2.0.17)
- zxing-core-source (ZXing Core 3.4.1) and zxing-android-embedded-local (4.3.0 source)
- androidx-activity-local
- androidx-core-local
- androidx-appcompat-local
- androidx-appcompat-resources-local
- androidx-recyclerview-local
- androidx-swiperefreshlayout-local
- androidx-versionedparcelable-local and androidx-versionedparcelable-compiler-local

AndroidX production source and resources came from the supplied androidx-main snapshot. VersionedParcelable and its unpublished annotation processor are also local source modules.
The app references these modules through Gradle project dependencies. The local Core source
is used instead of the AndroidX Core Maven AAR, including the Kotlin extension sources; the
old Core KTX dependency is excluded to avoid duplicate classes. The Core module uses the
local Guava source for ListenableFuture. ZXing's generated R namespace matches the imports in the supplied embedded scanner source. SLF4J's provider service descriptor is configured
for APK resource merging.

Still temporarily resolved from Maven. Some source for these components exists in the large AndroidX repository snapshot, but those multiplatform/generated/convention-based modules have not been converted into verified standalone Gradle projects in this pass: AndroidX Annotation, Lifecycle, SavedState, Fragment,
Collection, CursorAdapter, DrawerLayout, Emoji2, VectorDrawable, ResourceInspection,
ProfileInstaller, Tracing, Interpolator, CustomView, NavigationEvent, ConcurrentFutures, Kotlin Coroutines, Guava FailureAccess and annotation-only dependencies,
plus JSr305/JCIP annotations. Gradle/AGP and Android SDK are build tools, not bundled libraries.

Source compile spot-check: direct javac compilation passed for Bouncy Castle 1.83, Protobuf Java Lite
4.36.2, SLF4J API 2.0.17, and ZXing Core 3.4.1 using Java 8 source/target compatibility.
This checks those standalone source groups only; it does not verify Android resources, Kotlin modules,
transitive Maven dependencies, R8, or the final APK.

Build verification status: not confirmed. A local build requires Gradle 9.6.0, Android SDK API
37, and Maven access for the remaining dependencies. The current execution environment has no
Android SDK installed, and the Gradle wrapper distribution must be downloaded before tasks can
run. Do not treat this package as a verified Release build until `./gradlew clean assembleRelease`
succeeds in a configured Android SDK environment.

JSpecify 1.0.0 source is integrated as standalone :jspecify-source module; guava-source depends on project(':jspecify-source'). No Maven JSpecify dependency is required.
