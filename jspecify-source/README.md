# JSpecify source module

Contains the four annotation source files from JSpecify 1.0.0 (`org.jspecify:jspecify:1.0.0`): `Nullable`, `NonNull`, `NullMarked`, and `NullUnmarked`.

The source is compiled locally; this module has no external dependencies. Licensed under Apache-2.0; see the upstream JSpecify project and license notice in the source files.
